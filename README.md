# Claude daily assistant skills

Two Claude skills that work as a pair:

- [`morning-startup`](morning-startup/SKILL.md) — builds a time-blocked day-plan dashboard and calendar reminders from your calendar, inbox and task files.
- [`end-of-day`](end-of-day/SKILL.md) — a short debrief that writes your journal, trackers and a handoff for the next morning.

The skills hold no personal data; your details live in small state files in your own folder. See [SETUP.md](SETUP.md) to get started.
